## Demo Video Outline (30-60 seconds)

### Script
1. **0-5s:** WayFinder logo and tagline: "AI assistant for the visually impaired"
2. **5-15s:** User opens app, grants camera/microphone permissions
3. **15-25s:** User says "WayFinder, what is in front of me?" — app responds with spoken guidance
4. **25-35s:** User taps Analyze — scene description with obstacle detection appears
5. **35-45s:** Show TalkBack/VoiceOver navigation of the interface (if possible)
6. **45-55s:** Show Stop/Repeat buttons in action
7. **55-60s:** Safety disclaimer: "WayFinder is assistive support only. Not a replacement for mobility aids."

### Production Notes
- Record on a real Android device with TalkBack if possible
- Avoid showing identifiable people or private locations
- Include captions/subtitles for accessibility
- Background music: optional, keep minimal and non-distracting
